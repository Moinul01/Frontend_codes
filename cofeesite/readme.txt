# ☕ Brew & Bean — Coffee Shop Website

A modern, fully responsive, multi-section coffee shop website built with clean semantic HTML5, custom CSS3 (Flexbox), and interactive JavaScript.


 Features

Smart Header: Features a dynamic "hide-on-scroll-down / show-on-scroll-up" effect for a clean browsing experience.
Fully Responsive Design: Adapts smoothly across all devices using tailored breakpoints (`1200px`, `900px`, and `640px`).
Interactive Mobile Menu: Slide-out drawer menu complete with a backdrop blur overlay and automatic menu-closing on link selection.
Menu & Gallery Grid Systems: Uniform card layouts built with CSS Flexbox and custom mathematical `calc()` rules.
Testimonials Carousel: Powered by **Swiper.js** for smooth customer review navigation.
Contact & Footer Sections: Clean grid-based contact form, info list, and styled footer with social media links.

---

 Built With

HTML5 — Semantic document structure
CSS3 — Custom properties (variables), Flexbox layouts, and media queries
JavaScript (ES6) — Scroll tracking logic and mobile navigation controls
Font Awesome — Vector icons for UI elements and social links
Swiper.js — Mobile-friendly touch slider for testimonials
